# Franklin Whole Home (FranklinWH)

> FranklinWH Energy Storage Inc. builds whole-home energy management and storage hardware for
> residential solar — the aPower lithium iron phosphate AC battery, the aGate energy management
> controller, and the FranklinWH app — coordinating solar, battery, grid, generator and EV power for
> backup, self-consumption, time-of-use arbitrage and off-grid operation. Founded 2019, San
> Francisco Bay Area, sold through a certified installer and distributor channel. FranklinWH
> publishes a partner API for authorised third-party owners, financiers, installers and service
> providers to read site and device data, monitor performance, receive operational alerts and
> perform approved remote device control.

Generated by API Evangelist. FranklinWH does not publish an llms.txt of its own
(https://www.franklinwh.com/llms.txt returns 404); this file is assembled from the company's public
surface and the artifacts in this profile.

## APIs

- [FranklinWH API](https://api.franklinwh.com/): The partner API. 38 operations across a standard
  namespace (/api-common/) and a Sunrun-specific namespace (/api-sunrun/). Token auth: a cp/ck
  credential pair is exchanged at POST /api-common/tokenizer for a token sent in the Authorization
  header. Published base URL: https://test-api.franklinwh.com (free test environment). The
  production base URL is issued during partner onboarding and is not published.

## Capabilities

- Sites — query, list (offset paginated, max 50/page), modify, delete
- Devices — inventory, device information, parameters, running status
- Device data — power, peak power, energy, power-source breakdown, telemetry grouping, inventory,
  historical load
- Warnings and events — historical device warnings, grid-outage/backup events
- System settings — time-of-use profiles, aPower battery start/stop, smart circuits (up to 3 per
  device, load shedding by state-of-charge threshold)
- Grid events — scheduled grid interactions with reserve SOC and feed-in control
- Groups — device grouping and bulk settings applied across a fleet
- Modification records — audit log of every setting change, 11 record types
- Sunrun namespace — site pre-creation, backfill, asset listing, energy-management parameters,
  aPower switch

## Notes for agents

- Check the response envelope `code`, not the HTTP status. Auth failures return HTTP 200 with
  `{"code": 401, "msg": "wrong token"}` or `{"code": 403, "msg": "missing token or token param"}`.
- No idempotency key exists anywhere in this API. Several write operations start and stop a physical
  home battery or shed household circuits. Never blind-retry a write; re-read state instead.
- No rate-limit response headers and no documented 429, though FranklinWH states rate limiting is
  enforced.
- No MCP server, no A2A agent card, no /.well-known/ documents, no webhooks or AsyncAPI, and no
  first-party SDK. The packages that exist are community-maintained.
